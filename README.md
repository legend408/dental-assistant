# 牙科诊疗助手
这个项目是向学校行知训练营申请的团队项目
## 项目定位
这是用于辅助医生的工具，不是替代医生工作，每次AI的输出都会经过医生确认才能发给患者
## 目录结构
- `frontend/`:前端代码
- `backend/`:后端代码
- `docs/`:各种说明文档
## 技术栈
- 前端用vue3+vite，JavaScript
- 后端用FastAPI+Uvicorn，Python
- 数据库用SQLite

# 专有名词学习
- 响应式：想象你家有一个智能白板和好几个接收屏幕(比如客厅、卧室都能看到同一块白板的内容)。
你在白板上写字 → 所有屏幕自动跟着显示最新内容,不用你一个个屏幕去改
这就是"响应式"的意思:你只管改"数据源"(白板),显示的地方会自动跟着变,不用你手动一个个去改页面上的文字
- const message = ref('请选择你的角色')
这一行,就是造了一块智能白板,取名叫 message,上面现在写着"请选择你的角色"这几个字。
- 如果你想看白板上写的是什么,或者改白板上的内容,不能直接说"改 message",
要说"改 message.value"——.value 就是"打开白板、能看到/写字的那一面"。
